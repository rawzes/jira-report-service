Об отчете

Формируется отчет по производительности сотрудников на основе данных Jira. Выгружаются данные по пользователям из группы IT. Отчет всегда включает разбивку по проектам и исходные данные.

  • Пропускная способность (throughput) — количество выполненных задач
  • Время цикла (cycle time) — среднее время от старта до завершения задачи
  • Стареющие задачи в работе (aging WIP) — задачи, застрявшие в процессе
  • Просроченные задачи (overdue tasks) — задачи с нарушенным сроком
  • Переоткрытые задачи (reopened tasks) — задачи, возвращенные в работу
  • Метрики по сотрудникам — детальная статистика работы каждого сотрудника
  • Разбивка по проектам — распределение задач и метрик по проектам
  • Исходные данные (raw data) — полная выгрузка всех задач с деталями
